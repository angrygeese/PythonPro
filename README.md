# PythonPro2026

## О проекте

Программный конвейер на основе библиотеки RDKit для хемоинформатического анализа молекул:

1. определяет молекулу по нотации SMILES из файла `data/molecules.csv` (столбцы `mol_id`, `smiles`) и представляет в виде объекта;
2. санирует полученный объект и вычисляет следующие свойства: 
   - молекулярный вес (столбец `MW`);
   - коэффициент распределения октанол/вода по атомному методу Уайлдмана и Криппена (столбец `LogP`);
   - топологическую полярную площадь поверхности (столбец `TPSA`); 
   - число доноров водородной связи (столбец `HBD`);
   - число акцепторов водородных связей (столбец `HBA`); 
   - число вращаемых связей (столбец `RotBonds`); 
   - число колец (столбец `Rings`);
   - количественную оценку «лекарственноподобности» (столбец `QED`).
3. проверяет соответствие правилу пяти Липински (столбец `Ro5_pass`);
4. кластеризует молекулы алгоритмом Бутины (на основе 4096-битных «молекулярных отпечатков»);
5. строит TMAP-раскладку и сохраняет интерактивную визуализацию (Faerun) и таблицу с вычисленными свойствами.

Структура:

```
code/
├── reference_pipeline.py                 # основной скрипт
├── .python-version                       # используемая версия Python
├── pyproject.toml                        # зависимости
└── uv.lock                               # зависимости
data_folder/
├── processed_data/
|   ├── molecules_processed_valid.csv     # таблица с вычисленными свойствами для санированных нотаций SMILES
|   ├── molecules_processed_invalid.csv   # таблица с нотациями SMILES, не прошедшими санацию
|   ├── molecules.html                    # интерактивная HTML-визуализация TMAP-раскладки
|   └── molecules.js                      # технический файл для HTML-визуализации
├── raw_data/
└── tables/
    └── molecules.csv                     # исходная таблица с нотациями SMILES
```

## Системные требования

- Python 3.12 или новее
- [uv](https://docs.astral.sh/uv/)
- Windows 11 версии 25H2 или новее с установленной WSL2
- Ubuntu 24.04.3 LTS или новее
- Основные зависимости (см. раздел "Инструкция по запуску"):
   - `rdkit`
   - `tmap2`
   - `faerun`
   - `numpy`
   - `matplotlib<3.9`
- Совместимый браузер для просмотра HTML-страниц.

## Инструкция по запуску

1. Клонируйте репозиторий и перейдите в директорию `PythonPro2026/code`:

   ```bash
   git clone <URL репозитория>
   cd PythonPro2026/code
   ```

2. Создайте окружение и установите зависимости:

   ```bash
   uv sync
   ```

3. Запустите программный конвейер:

   ```bash
   uv run python reference_pipeline.py
   ```

4. Результаты появятся в директории `PythonPro/data_folder/processed_data`.
